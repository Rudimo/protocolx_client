# PROTOCOL-X — клиентская презентация

Публичная витрина для подписчиков, потенциальных клиентов и инвесторов.

**Live:** https://rudimo.github.io/protocolx_client/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Презентация 12 слайдов — открывается прямо в GitHub Pages |
| `beta-story.svg` | 9:16 сторис для соц-сетей (1080×1920) |

## Как обновлять

```bash
git add index.html
git commit -m "обновил <что>"
git push
```

GitHub Pages подхватит изменения через ~1 минуту.

## Управление презентацией

- **Скролл / стрелки ↓↑** — следующий/предыдущий слайд
- **Space / PageDown** — следующий
- **Home / End** — первый / последний
